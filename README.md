# TCFcan 听力答题提示

用于 [TCFcan 听力刷题](https://tcfcan.com/practice/listening) 的 Tampermonkey（油猴）脚本。

**[点击安装脚本](https://raw.githubusercontent.com/mpftc/tcfcan-listening-helper/main/tcfcan-listening-helper.user.js)** · [查看源码](./tcfcan-listening-helper.user.js)

## 功能

- 答对：播放约 0.35 秒的上扬音效。
- 答错：播放约 0.42 秒的低沉音效，随后从头重播本题一次。
- 保留所选答案、正确答案和解析；不自动点“重做”或切换下一题。
- 重播使用网站已有播放器，保留当前倍速和题目音量，并清除单句播放的结束位置。
- 每次提交只触发一次。查看旧题、刷新已答题、开启“背答案”均不自动提示。
- 错误音效期间手动操作或切换题目，会取消待执行的自动重播。

## 安装

1. 在 Chrome / Edge 中安装官方 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开上方“点击安装脚本”，在油猴页面点击“安装”。
3. 刷新 TCFcan 页面，进入听力练习，正常选择并提交答案。

如果安装链接显示源代码：在油猴控制面板中新建脚本，使用本仓库 `.user.js` 文件的**全部内容**替换编辑器内容并保存。

提示音在首次点击或键盘操作时启用。如果浏览器阻止播放，页面会显示启用声音的按钮。音效由浏览器生成，无需下载音效文件。

## 设置与试听

在 TCFcan 页面点击浏览器工具栏的油猴图标，可找到：

| 菜单 | 说明 |
| --- | --- |
| 听力助手 | 总开关，关闭时提示音和自动重播均停用 |
| 错题重播 | 单独控制重播；关闭后仍保留对错音效 |
| 提示音音量 | 0–100%，默认 35%；不改变题目音量 |
| 试听：答对音效 | 单独试听上扬音效 |
| 试听：答错音效 | 单独试听低沉音效，不触发题目重播 |

设置保存在油猴本地存储。脚本包含 GitHub 更新地址，可由油猴检查后续更新。

## 适用范围与实现

仅在 `/practice/listening` 及对应中英文等语言路径执行答题监听，不覆盖阅读和模考。`@match` 覆盖 TCFcan 域名，是为了支持从首页进入练习的站内路由切换；运行时仍检查听力练习路径。

脚本监听用户点击“提交 / Submit”或按 Enter，然后等待选项出现本次判题结果。识别依据是页面公开 DOM 的 `data-module="listening"`、题目编号、选项编号、`aria-disabled` 及选项状态类。它不读取隐藏题库、不代答、不拦截网络、不修改保存记录、不上传浏览数据。

重播使用网站的暂停/播放按钮及进度条。网站更新这些标记后可能需要适配；无法明确识别结果或播放器时，脚本会跳过操作或显示手动重播提示。

- 18 项自动化测试通过：对错反馈、去重、旧题/背答案不误触发、重做、Enter、切题和音源切换取消重播、手动接管、开关、音量设置与音效生成。
